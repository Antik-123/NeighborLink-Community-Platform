# NeighborLink – Powered by People, Driven by Kindness

## About the Project

NeighborLink is a group project that aims to connect people who need help with nearby neighbors who are willing to provide assistance.

It is a web-based, hyper-local community assistance platform designed to make neighborhood support more organized, accessible, and trustworthy.

## Key Features

- User Registration & Login
- Create and Manage Help Requests
- Location-Based Task Discovery
- Task Claiming and Completion
- Real-Time Messaging
- Rating and Review System
- AI-Based Helper Matching
- Tool and Household Item Lending
- Admin Monitoring and Content Moderation
- Community Badges and Leaderboards

## Problem

People often need help with small everyday tasks such as grocery pickup, borrowing tools, moving furniture, or short-term assistance. Existing solutions such as social media groups and messaging apps are often unorganized and lack proper trust and task-management features.

## Our Solution

NeighborLink provides a centralized platform where users can post help requests and nearby neighbors can discover, respond to, and complete those tasks in an organized environment.
